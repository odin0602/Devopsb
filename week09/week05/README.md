# 5주차 - Docker

## 오늘 배운 내용

- 도커란?
  - 앱을 개발, 배포, 실행하기 위한 오픈 플랫폼
  - 앱과 실행환경을 컨테이너로 묶어서 다른 환경에서도 돌아가도록 도와줌
  - VM보다 상대적으로 가벼움

- Image: 컨테이너를 만들기 위한 읽기 전용 템플릿(붕어빵 틀)
- Container: 이미지로부터 생성된 인스턴스(붕어빵)
- Dockerfile: 이미지를 어떻게 만들지 작성하는 파일
- Registry: 이미지를 저장 및 공유하는 곳

- 도커 설치

- 하이퍼바이저 VS 컨테이너
  - 하이퍼바이저: 
    - 무겁다
    - 상대적으로 느린 시작
    - 이미지 크기가 크다
    - 강한 격리
  - 컨테이너:
    - 커널 공유
    - 일반적으로 빠르게 시작
    - 이미지 크기가 작다
    - 프로세스 수준으로 격리

- namespace
  - 시야 격리(안보이게 만들기)

- cgroup
  - 자원 사용량 관리(많이 못쓰게 만들기)

- 깃허브 이슈 작성 방법
  - 저장소에서 이슈탭 -> New issue
  - 완료 항목은 체크박스로 진행상황 표시

- Issue -> Branch -> 기록 -> Commit/Push -> PR -> Merge -> Issue Close
