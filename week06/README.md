# 6주차 - Docker 파일

## 오늘 배운 내용

- Dockerfile: 이미지 빌드 레시피, 실행 환경을 코드로 정의
  - FROM: 기반 이미지 선택
  - WORKDIR: 작업 디렉터리 설정 (cd와 유사)
  - COPY: 호스트 파일을 이미지 안으로 복사
  - RUN: 이미지 만들 때 실행 (예: 라이브러리 설치)
  - CMD: 컨테이너 켤 때 실행 (예: 앱 실행)
  - ENV: 환경 변수 설정
  - EXPOSE: 사용 포트 정보 선언 (실제로 열리지는 않는 문서화 용도)

- 설정 우선순위: 코드 기본값 < ENV < docker run -e

- 레이어 캐시
  - 한 레이어가 바뀌면 그 아래 레이어는 전부 다시 만들어짐
  - 따라서 자주 바뀌는 코드를 맨 뒤에 두면 재빌드 시간을 크게 단축 가능

- ghcr.io로 이미지 공유하기
  - GitHub 계정을 활용해 ghcr.io에 로그인
  - tag로 이미지 주소 및 태그 지정 후 push로 업로드
  - 친구가 내 이미지를 다운받으려면 GitHub Packages 설정에서 접근 권한을 'Public'으로 변경해야 함

- 멀티 아키텍처 빌드: 애플 실리콘 맥(arm64)과 일반 윈도우 PC(amd64) 양쪽에서 모두 잘 돌아가게 하기 위함
